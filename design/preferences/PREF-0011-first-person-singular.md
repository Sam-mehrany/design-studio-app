# PREF-0011 — First person singular; one author, never a corporate "we"

**Polarity:** like
**Facet terms:** `H.PERS.first-singular` ✓ · `H.PERS.first-plural` ✗
**Scope:** Sam's own portfolio, case studies and hiring-task deliverables
**Evidence:** the Markito hiring-task copy says «من», never «ما» — Sam did the work alone (2026-10)
**Date:** 2026-10-07

**The preference.** Where the work is Sam's own, the voice is "I" / «من». No corporate
plural, no implied team.

**Why.** The plural claims a team that does not exist, which both misrepresents the work and
weakens it — a solo end-to-end piece is the more impressive fact.

**Exceptions.** Product copy for a real company or platform is a different voice; this rule
covers personal and case-study work. Not yet decided for the training product's own
interface copy.
