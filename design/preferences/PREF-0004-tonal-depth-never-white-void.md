# PREF-0004 — Tonal depth and a staged environment; never a white void

**Polarity:** like
**Facet terms:** `A.FAM.fluent` ✓ · `A.FAM.spatial-3d` ✓ · `C.VAL.tonal-layered` ✓ · `C.VAL.white-void` ✗ · `E.DEP.tonal` ✓ · `E.ENV.staged` ✓ · `E.ENV.tonal-field` ✓ · `E.ENV.white-void` ✗ · `B.GRID.bento` ✓ · `F.3D.product-studio` ✓
**Scope:** brand graphics, design-system presentation, marketing surfaces
**Evidence:** Sam's own stated references for the Bit. promo graphics were the Microsoft Fluent 2 hero and the Google Design Gemini tile grid; the Fluent 3D material set (velvet, frosted glass, terrazzo, brushed steel) was the style reference; and the rule he gave for the AI pass was that Bit. visuals need "a tonal set with environment depth, never a white void" (2026-10-20/21)
**Date:** 2026-10-21

**The preference.** Objects sit in a space: a graded tonal field, a ground plane, falloff,
reflection. Depth comes from layered surface tone rather than from drop shadows on white.
Tight unequal tile grids (bento) are a liked structure for presenting a system's parts.

**Why.** An environment makes rendered objects read as objects rather than as stickers, and
tonal layering carries depth without the shadow stacking that a white background forces.

**Exceptions.** Product UI has not been tested against this — a light product theme is not
automatically a "white void". Scope stays on brand and presentation work until there is
evidence either way.
