# PREF-0009 — Neutral grotesque for Latin, IRANSans-class for Persian

**Polarity:** like
**Facet terms:** `D.FACE.neo-grotesque` ✓ · `D.FA.iransans-class` ✓
**Scope:** all work
**Evidence:** the Bit. wordmark is set in Helvetica Bold; the Farsi edition of the design system is set in IRANSans (2024–2026)
**Date:** 2026-10-29

**The preference.** Latin type comes from the neutral grotesque lineage — Helvetica, Inter
and relatives. Persian type comes from the IRANSans family of neutral UI faces. Neither is
chosen for personality; both are chosen for disappearing.

**Why.** A neutral face lets structure and hierarchy carry the design, which is consistent
with how the rest of the taste record reads. It also pairs predictably across the two
scripts, which a more characterful face would not.

**Exceptions.** Display and brand moments are untested — there is no evidence yet about
whether an expressive display face is welcome for a headline, so `D.PAIR.display-text`
stays `–`.
