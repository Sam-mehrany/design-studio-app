# REF-0066 — Low-angle laptop mockup — light agency site, ALL-CAPS statement headline, mono nav, two-up photography

## Read

Measured: hex values and WCAG ratios sampled from the original file with Python/PIL (median of a region for grounds, extreme-luminance pixels for text, so anti-aliasing can pull a ratio slightly low); cap heights by row profiling where stated. Anything marked *estimated* was read by eye.

**Colour.** UI is neutral only: page `#d9d9d9`, type `#000000`, secondary `#656565`, mono nav `#494949`. All hue comes from the two photographs (saturated amber `#d58004`, rust `#4e160c`). Scene is a near-black tonal field `#121318` over blue-grey cloth `#6b7284`.

**Typography.** Three-line ALL-CAPS neo-grotesque statement, flush-left, tight: cap height 10px on 12px line pitch (800px original). Stat labels in tracked caps at 4px cap height — headline-to-label 2.5×. Nav is monospaced caps. One sans + mono accent.

**Layout & harmony.** Columnar: a thin rule under the nav, the statement block, then a four-column stat row whose labels align to the image grid below, then a two-up image row. Generous top space, size ranks.

**Shape & surface.** Square corners, hairline rule, no shadows; images framed within margins.

**Buttons & components.** No buttons visible — nav items in mono caps carry all interaction ("GET IN TOUCH").

**Gradient & imagery.** Photography is the colour and the content; delete it and the page is grey type only (hard).

**Contrast.** Headline `#000000` on `#d4d4d4` = 14.2:1; mono nav `#494949` on `#cecece` = 5.72:1; stat labels `#656565` on `#d9d9d7` = 4.12:1 — fails.

## Why the verdict

Swiss type-and-grid discipline with a mid-grey page ground is cheap and transferable; the shot depends entirely on its photography. Concept → adapt.
