# REF-0089 — Studio display on marble slab and concrete plinth — iridescent light-ribbon wallpaper, grey studio

## Read

Measured: hex values and WCAG ratios sampled from the original file with Python/PIL (median of a region for grounds, extreme-luminance pixels for text, so anti-aliasing can pull a ratio slightly low); cap heights by row profiling where stated. Anything marked *estimated* was read by eye. These pins are ~564px wide, so small UI text is only 3–6px tall in the file; its sampled ratio reads lower than the designed colour would, and is flagged where that matters.

**Colour.** Neutral scene: wall `#b2b2b0`–`#c7c8ca`, marble slab `#bebebe`, concrete plinth `#74706d`, silver stand `#828280`. All saturation is on the screen: black `#030305` with a rainbow ribbon peaking in violet `#462cc7` and warm hues.

**Typography.** None on screen.

**Layout & harmony.** Display centred on a stacked slab-on-plinth, front-on, generous empty wall. Symmetric.

**Shape & surface.** Polished marble against rough concrete; the device is the subject.

**Buttons & components.** None.

**Gradient & imagery.** Wallpaper render is the only content (hard).

**Contrast.** Not applicable (no text). The saturated screen against a fully neutral set is what pulls the eye.

## Why the verdict

A mockup template (ply.supply) with no UI on screen; useful only as staging reference. Adapt, low.
